# CONTEXT.md — контекст проекта DOCS-course-bot

Быстрое введение для нового читателя (или AI-агента) — читается за 3 минуты.

## Что это

**DOCS-course-bot** — репозиторий-документация для проекта **Telegram-курс-бота с Mini App**. Здесь **только тексты архитектуры** — код в отдельном репозитории `course-bot`.

## Что за продукт

Курс личной трансформации на 4–6 модулей (28-дневные блоки). Участник проходит день за днём в Mini App, Автор проверяет рефлексии в Рабочей группе через бота, деньги идут через PSP в РФ. Система жёстко удерживает дисциплину: 3 жизни на этап, отчёт по каждому дню, дедлайны по серверному времени.

## Три уровня документации

```
architecture/               ← источник истины
├── 00…17, 99               ← блоки корпуса (consolidated v3)
├── normative/              ← нормативный стек (И1–И4, Б17, SEAM, ERRATA)
├── appendix/               ← приложения A/B/C/D (сквозные реестры + дефекты)
├── build/                  ← артефакты сборки (Mini App-first)
├── debt/                   ← артефакты долга
└── _WIP-architecture-split.md  ← служебный журнал нарезки
```

Источник истины в узком смысле — «файлы корпуса `00`…`99` + `normative/*` + `appendix/*`».
`build/` — производный, отражает истину в исполняемой форме.
`debt/` — закрытые артефакты долга по блокам.

## Нормативный стек и старшинство

Восемь узлов, снизу вверх по хронологии:

```
корпус v3 → И1 → И2 → И3 → И4 → Б17 → SEAM-PATCH-1 → ERRATA-UNIFIED
```

**ERRATA-UNIFIED — высшая ступень**, побеждает всех. SEAM-PATCH-1 стоит ниже ERRATA. Подробнее — [architecture/normative/README.md](architecture/normative/README.md).

## Ключевые архитектурные факты

- **Mini App-first.** Основной пользовательский опыт — в Mini App. Бот держит уведомления, admin-команды и Menu Button.
- **Точка создания участника** — first-launch Mini App (SEAM-PATCH-1).
- **35 admin-команд** в реестре Б17. Всегда через whitelist + hard-confirm (E3 ERRATA).
- **`participant_state`** — обычная таблица с проектором (E1 ERRATA), не materialized_view.
- **CSP Mini App** — `default-src 'self'` с белым списком, `unsafe-eval` запрещён (E2 ERRATA).
- **`text_registry`** — единый источник текстов, три тона, `{домен}.{имя}` (И4).
- **22 риска** в реестре (RISK-L-01…22), каноническое число (E4 NOTE1).
- **Хостинг в РФ** (152-ФЗ) — Yandex Cloud или Timeweb «Облако 152-ФЗ».

## Что делать агенту-новичку

1. Прочитать этот файл (уже сделали).
2. Открыть [AGENTS.md](AGENTS.md) — правила работы.
3. Открыть [architecture/build/DIVISION.md](architecture/build/DIVISION.md) — карта «блок → уровень реализации».
4. Открыть [architecture/build/build-order.md](architecture/build/build-order.md) — порядок первых итераций.
5. Реализовать первую итерацию (Онбординг SEAM-1) в репозитории `course-bot`.

## Что НЕ делать агенту

- Не переписывать источник истины без указания Автора.
- Не выдумывать значения открытых решений (см. AGENTS.md, «Как задавать вопросы Автору»).
- Не создавать код в этом репозитории (`DOCS-course-bot`) — только правки документации.
