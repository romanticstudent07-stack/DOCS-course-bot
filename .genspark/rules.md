\# .genspark/rules.md — правила для Genspark Super Agent



Дополняет \[../AGENTS.md](../AGENTS.md) специфичными для платформы Genspark инструкциями.



\## Режим работы



Этот репозиторий подключается к Genspark через режим \*\*«Существующий код» → «Существующий проект GitHub»\*\*. Genspark клонирует репозиторий, читает `AGENTS.md` + `CONTEXT.md`, работает с файлами и создаёт pull-requests.



\## Атомарность PR



\- Одна задача — один PR.

\- Заголовок PR: `Блок N: <короткое описание>` или `\[Mini App|Bot|Backend]: <описание>`.

\- В описании PR — какие файлы из `architecture/` читались, какие правила ERRATA применялись.



\## Правила чтения



Genspark читает документы \*\*строго в этом порядке\*\*:



1\. `CONTEXT.md` (обзор)

2\. `AGENTS.md` (правила)

3\. `architecture/README.md` (реестр блоков)

4\. `architecture/normative/README.md` (нормативный стек)

5\. `architecture/build/DIVISION.md` (что где реализуется)

6\. Только после — конкретный блок под задачу.



Никогда не начинать с файлов корпуса без прохода по шагам 1–5.



\## Ветки



\- Работать всегда в feature-ветках, никогда напрямую в `main`.

\- Формат имени ветки: `agent/blockN-short-slug` или `agent/miniapp-slug` / `agent/bot-slug` / `agent/api-slug`.



\## Замечания для Genspark Super Agent



\- Задачи вида «переделай Приложение A» в текущей чате уже выполнены — см. коммиты в PR #2. Не переделывать.

\- Задачи вида «реализуй Блок N» → выполнять в репозитории `romanticstudent07-stack/course-bot`, а не здесь.

\- Ссылки на файлы в `architecture/build/` — использовать относительные, чтобы работали в оффлайне.



\## Открытые долги для Genspark



\- Заполнить `architecture/build/db-schema.sql` полными DDL.

\- Заполнить `architecture/build/config-schemas/` JSON-Schema для 8 конфигов.

\- Извлечь 50+ CI-чеков в `ci-checks.yaml`.



\## Что НЕ делать



\- Не публиковать `bot\_token` даже в тестовых файлах.

\- Не запускать деплой без явной команды Автора.

\- Не удалять/переносить файлы из `architecture/normative/` без обсуждения — там источник истины по старшинству.
